# АвтоМастер

Многостраничный сайт автосервиса. Учебный проект.

## Технологии

- HTML5
- Tailwind CSS
- JavaScript (vanilla)
- BEM-методология

## Страницы

- Главная — hero, услуги, преимущества
- Услуги — полный прайс с ценами
- Контакты — форма записи через Formspree

## Особенности

- Адаптивная вёрстка (mobile first)
- Семантическая разметка
- SEO мета-теги и Open Graph
- Accessibility (aria-label, aria-current, label/id)
- Бургер-меню на мобильных
- Валидация формы через JavaScript
